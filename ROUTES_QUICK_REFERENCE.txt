# 🚀 QUICK REFERENCE - ALL ROUTES

## PUBLIC ROUTES (No login needed)
```
/                   → Home
/quizzes            → Browse all quizzes
/quiz/:id           → Quiz details
/leaderboard        → Top students
/universities       → University list
/matieres           → Subjects
/niveaux            → Education levels
/faculties          → Faculties
/modules            → Study modules
/forum              → Discussion forum
/forum/question/:id → Question & answers
/forum/ask          → Post new question
/faq                → Frequently asked questions
/help               → Help center
/terms              → Terms of service
/privacy            → Privacy policy
/login              → Sign in
/register           → Create account
/forgot-password    → Reset password
```

## PROTECTED ROUTES (Login required)
```
/dashboard          → User home
/mes-quiz           → Your quizzes
/quiz/:id/play      → Take a quiz
/result/:attemptId  → View results
/results            → All results history
/saved              → Saved quizzes
/achievements       → Your badges
/profile            → Your profile
/settings           → Account settings
/subscription       → Plans & pricing
/payment            → Checkout
/premium            → Premium features
```

## ADMIN ROUTES (Admin only)
```
/admin              → Admin panel
/admin/quiz/create  → Create quiz
/admin/quizzes      → All quizzes
/admin/quiz/:id/edit   → Edit quiz
/admin/quiz/:id/attempts → Quiz data
/admin/users        → Manage users
/admin/users/:id    → User details
/admin/help         → Admin help
/admin/docs         → API docs
/admin/support      → Support tickets
```

## ERROR HANDLING
```
/anything-else      → Auto redirects to /
```

## FRENCH ALIASES
```
/classement    → same as /leaderboard
/resultats     → same as /results
/aide          → same as /help
/parametres    → same as /settings
/abonnement    → same as /subscription
```
